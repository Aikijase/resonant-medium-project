\section{Discussion and conclusion}
\label{sec:conclusion}

We presented the Echo Equation, a minimal finite-memory mechanism for late-time cosmic acceleration. It reproduces $\Lambda$CDM when memory vanishes, yet predicts a falsifiable, single-frequency residual in growth and lensing when memory is finite. The immediate next step is a joint RSD\,+\,lensing analysis that treats the echo frequency as a shared parameter while allowing survey-specific amplitudes. Confirmation would argue for an underlying resonant medium; a null result would bound memory to the percent level.
