# JCAP Submission Checklist (Echo Equation)

- [ ] Title, author, affiliation, email correct
- [ ] Abstract ≤ ~200 words, no citations
- [ ] Sections: Intro, Theory, Data, Results, Predictions, Consistency, Conclusion
- [ ] Figures: vector preferred (PDF), readable fonts, captions informative
- [ ] Refs in BibTeX; compile clean on Overleaf (main_jcap.tex)
- [ ] Acknowledgments & Conflicts present
- [ ] arXiv number (add in main_jcap.tex when ready)
- [ ] Compile without errors/warnings
